# OpenReel – multi-page site
Open via a local server (e.g. `python3 -m http.server 8000` in this folder) so every page shares the same browser storage.
Demo admin: admin@openreel.test / admin123 (change before going live). Replace https://your-domain.com in the HTML, sitemap.xml and robots.txt.
database/schema.sql = PostgreSQL/Supabase schema. Only add movies you have the right to stream.
