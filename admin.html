Connect to GitHub

This site is hosted on GitHub, so the admin panel saves your movies by committing changes to your repository.

How do I get a token?
  1. On GitHub open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Under Repository access choose “Only select repositories” and pick your site repository.
  3. Under Repository permissions set Contents to “Read and write”.
  4. Generate the token, copy it and paste it above. Treat it like a password.
